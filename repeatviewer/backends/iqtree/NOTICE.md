# IQ-TREE bundled binaries

These directories contain official **IQ-TREE 3.1.4** prebuilt binaries from the upstream project:

- **macOS** (`macos/bin/`): universal macOS build
- **Linux** (`linux/bin/`): universal Linux build (includes architecture-specific launchers where provided)
- **Windows** (`windows/bin/`): 64-bit Windows build

Source release: [iqtree/iqtree3 v3.1.4](https://github.com/iqtree/iqtree3/releases/tag/v3.1.4)

Only the contents of each platform’s `bin/` directory from the release archives are vendored here (executables and any sibling libraries shipped in `bin/`). Example alignment files from the archives are not included.

Please refer to the IQ-TREE project for licensing, citation, and documentation: https://github.com/iqtree/iqtree3
