# Bundled MAFFT

TEviewer bundles the official MAFFT 7.526 platform distributions downloaded
from https://mafft.cbrc.jp/alignment/software/:

- `macos/`: Universal 2 files extracted from `mafft-7.526-signed.pkg`
- `linux/`: 64-bit portable `mafft-7.526-linux.tgz`
- `windows/`: 64-bit all-in-one `mafft-7.526-win64-signed.zip`

The upstream distribution page describes the portable package as BSD licensed
and the Windows package as GPL licensed. The distributions can also contain
third-party components with their own notices. See the upstream license page:
https://mafft.cbrc.jp/alignment/software/license.html
